# CCITBook

## DISCUSSION

In building this application, I structured the architecture around a clean separation of concerns across models, services, and screens to ensure the codebase remains maintainable and efficient. I designed the **Models** layer to handle all data serialization and deserialization, using factory constructors to seamlessly map raw JSON payloads from the API into strongly typed Dart objects. These models are powered by the **Services** layer, where I wrote asynchronous HTTP methods to communicate directly with the DummyJSON endpoints for fetching posts, retrieving and adding comments, and handling user authentication. Finally, my **Screens** and **Providers** layers consume this data to drive the user interface, manage local states, persist user sessions using shared preferences, and handle global features like dynamic theme toggling.
